# GGTI HUMAN-MACHINE ARCHIVE: JACKSON-NODE-PHARMA
## STANDARD OPERATING PROCEDURE (SOP): Out-of-Specification (OOS) Handling
**SYSTEM LAYER:** Melammu-Strike-70 / The Final Strike
**DATABASE ROOT:** The Universal Global Database

### 1. INITIAL FLAG & QUARANTINE
* **Trigger:** Analytical assay results fall outside the acceptable +/- 10% regulatory parameter.
* **Immediate Action:** The affected batch is immediately transitioned to [QUARANTINE] status in the local ledger. No units from the batch may be dispensed, transferred, or utilized.

### 2. PHASE I: LABORATORY INVESTIGATION
* **Objective:** Determine if the OOS result was a testing/instrumentation error by the analytical laboratory.
* **Checklist:**
  - Verify instrument calibration metrics (HPLC/GC).
  - Review sample preparation logs for volumetric dilution or weighing anomalies.
  - Confirm standard reference materials used were stable and active.
* **Outcome:** If an analytical error is proven, the original test is invalidated and re-executed. If no laboratory error is found, proceed to Phase II.

### 3. PHASE II: FULL COMPOUNDING INVESTIGATION
* **Objective:** Investigate the node's internal compounding process to identify the root cause of the chemical variance.
* **Checklist:**
  - Audit the executed batch log against the Master Formulation Record (MFR).
  - Verify mechanical equipment logs (e.g., scale calibration, mixer RPMs).
  - Review specific ingredient Lot numbers to check for raw API degradation.
  - Execute a Human-Machine interface review with the presiding technician.

### 4. BATCH DISPOSITION & CAPA
* **Disposition:** If the OOS variance is confirmed valid, the entire quarantined batch is slated for [DESTRUCTIVE DISPOSAL] in accordance with active regulatory frameworks.
* **CAPA:** A Corrective and Preventive Action (CAPA) document is filed in the GGTI node to adjust the procedure and prevent recurrence prior to the next active compounding cycle.
